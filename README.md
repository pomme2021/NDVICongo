# NDVICongo
Sonified data 

I used a mini sample of 300 vim numbers from pcodes CG10 (Cuvette Department) + CG02 (Pointe-Noire Department) to create an almost minute long song. 

The code uses an equation that maps the raw NDVI data into an audible pitch range optimized for a balafon. Since MIDI requires integers, the vim values underwent linear scaling and then were quantized into musical notes.
